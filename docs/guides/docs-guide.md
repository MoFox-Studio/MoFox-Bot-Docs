第一次来，不必把左侧目录全部读完。先了解 [Neo-MoFox 是什么](/docs/guides/about)，再去 [部署方式怎么选](/docs/guides/choose) 选一篇安装教程；已经装好的人，可以直接找配置、插件或维护相关章节。

这一页介绍文档站的导航、搜索和反馈工具。正文里保留了可以实际点击的按钮，读到时可以顺手试试。

## 搜索：按 Ctrl K，直接找关键词

点顶栏的 **搜索**，或按 <kbd>Ctrl K</kbd>（Mac 是 <kbd>⌘ K</kbd>）打开搜索框。可以先输入具体的名词或报错，比如「主人」「WebSocket」「API Key」。

![文档站搜索入口，按钮右侧显示 Ctrl K 快捷键](/guide/docs-guide/search-button.png)

- 用 <kbd>↑</kbd>、<kbd>↓</kbd> 选择结果，<kbd>Enter</kbd> 打开，<kbd>Esc</kbd> 关闭。
- 搜索也提供 AI 提问入口，可以用完整问题描述你想做什么。
- AI 回答适合帮你定位文档；执行命令或修改配置前，点开它引用的原文核对步骤与适用环境。

![搜索框提供关键词搜索和 AI 提问入口，并显示键盘操作提示](/guide/docs-guide/search-modal.png)

## 深色模式与阅读增强

顶栏的 **太阳 / 月亮** 开关可以切换浅色与深色模式。手动选择会保存在浏览器里；尚未手动选择时，站点跟随系统主题。

<DocButtons :items="['theme']" />

![深色模式下的文档页，导航、正文和代码区使用暗色背景](/guide/docs-guide/dark-mode.png)

**书本图标**打开「阅读增强」菜单：

| 功能 | 适合什么时候用 |
| --- | --- |
| **布局切换** | 宽屏阅读长代码、表格时，可以调整内容和侧边栏的宽度；需要时再切回原始布局 |
| **聚光灯** | 阅读较长段落时，让鼠标附近保持高亮，其余部分变暗 |

![阅读增强菜单中的布局选项与聚光灯开关](/guide/docs-guide/readability-menu.png)

## 报告问题：在出错的页面点虫子

顶栏最右侧的 **虫子图标**是文档反馈入口。它会自动带上当前页的标题、地址、源文件路径和浏览器环境，方便维护者找到你正在看的内容。首页与明确关闭反馈的页面不显示此按钮。

1. **未登录时**，点击虫子会前往 GitHub 授权；授权完成后回到原来的文档页。
2. **登录后**，再次点击虫子，在本站弹窗中修改标题和正文。写清「哪一步有问题」「实际看到了什么」「你期望看到什么」，有复现步骤或截图可以一起补充。
3. 点 **提交**，成功后弹窗会展示新 Issue 的链接，可以打开查看后续讨论。
4. 顶栏会显示你的 GitHub 用户名与头像；从用户名旁的菜单可以 **退出登录**。关闭标签页后，本次登录状态也会失效。

![站内反馈弹窗的实际界面：修改标题和正文后提交 Issue，底部保留直接去 GitHub 提交的入口](/guide/docs-guide/feedback-modal.png)

弹窗按 <kbd>Esc</kbd> 或点击遮罩可以关闭。授权取消、登录失败或提交出错时，页面会显示中文提示；你可以重试，也可以使用 **不登录，直接去 GitHub 提交** 的入口。直接入口会打开 GitHub 的新 Issue 页面，最终提交仍需要在那里登录 GitHub。

::: tip 提交前检查一下内容
预填信息是用来定位页面的。补充日志或截图时，请遮住 API Key、访问密钥以及不希望公开的账号信息；Issue 发布后会出现在公开仓库中。
:::

下面保留的是传统的 **直接去 GitHub 提交** 按钮，也会自动附带本页信息。要体验站内登录与编辑，请使用顶栏的虫子图标。
