# 文档使用指南

这一页不讲 Bot，讲**文档站本身**。

每一页文档的右上角都有一排小按钮，它们能帮你快速找内容、保护眼睛，甚至一键给文档提意见。本页会把它们逐个讲清楚——并且每个按钮下面都放了同款的**真按钮**：不是截图，现在就可以点。

![图片：文档站右上角的四个按钮，从左到右依次是深色模式开关、GitHub 图标、阅读增强菜单、报告问题（小虫子）](/guide/docs-guide/navbar-buttons.png)

从左到右依次是：**深色模式开关**、**GitHub 仓库入口**、**阅读增强菜单**、**报告问题**。再加上顶栏最左边的**搜索框**，一共 5 个工具，下面挨个介绍。

## 搜索：找不到东西就按 Ctrl K

![图片：顶栏的搜索按钮，右侧标注快捷键 Ctrl K](/guide/docs-guide/search-button.png)

- 点顶栏的 **搜索** 按钮，或者直接按 **Ctrl K**（Mac 是 <kbd>⌘ K</kbd>），搜索框会立刻弹出。
- 输入关键词，整个文档站的内容都能搜出来：<kbd>↑</kbd> <kbd>↓</kbd> 选择，回车打开，<kbd>Esc</kbd> 关闭。
- 它还能当 **AI 问答**用：切换到提问模式后直接用大白话问，比如「启动器怎么装插件」「人设写在哪」，它会检索文档后回答你。翻文档翻不到的时候特别好用。

![图片：搜索弹窗，输入框占位文字为「搜索文档或向 AI 提问」，底部提示导航、选择、关闭等快捷键](/guide/docs-guide/search-modal.png)

## 深色模式：晚上看文档不刺眼

顶栏上的**太阳 / 月亮**开关，一键在浅色和深色主题之间切换：

- 手动切换后，选择会被**记住**，下次打开还是你选的样子。
- 从没手动切换过时，它会**自动跟随系统**的深色模式设置。

## 阅读增强菜单：把页面调成你舒服的样子

**书本图标**点开是「阅读增强」面板，里面有两样东西：

| 功能 | 干什么用 |
|---|---|
| **布局切换** | 调整页面宽度。默认「原始宽度」；「全部展开」能让内容占满屏幕，还可以把侧边栏和内容区的宽度各自拖宽拖窄。屏幕大、想看长代码块的用户会舒服很多 |
| **聚光灯** | 开启后，页面只有**鼠标附近**的区域保持高亮，其余部分变暗，像拿着手电筒看书。适合逐行啃长教程 |

![图片：阅读增强菜单展开的样子，上方是布局切换的四个选项，下方是聚光灯的 ON / OFF 开关](/guide/docs-guide/readability-menu.png)

## 报告问题：发现文档错了？一键开 Issue

最右边那个**小虫子**是「报告问题」按钮，用法很简单：

1. 在**出错的那一页**，点击虫子图标。
2. 会打开 GitHub 的新 Issue 页面，**标题和页面信息已经自动帮你填好**——包括页面标题、地址、对应的源文件、浏览器环境、主题色等。
3. 你只需要补充**问题描述**和**复现步骤**，提交即可（需要登录 GitHub 账号）。

因为页面信息是自动附带的，我们不用再来回问「你说的是哪一页」，修起来快多了。发现错别字、步骤过时、截图对不上，都欢迎随手一点。
